## 先搞清楚：CN2、CN2 GT、CN2 GIA 到底差在哪

中国电信的出口线路不止一种，搬瓦工官网自己把这件事讲得挺直白。简单说：

- **AS4134（ChinaNet/163 网）**：最便宜、最常见，也最容易堵。晚高峰丢包率能到 30% 以上，做正经业务基本别指望。
- **AS4809 CN2 GT（Global Transit）**：原本是为了缓解 163 拥堵搞的，但 2019 年之后也堵得差不多了，性价比不高。
- **AS4809 CN2 GIA（Global Internet Access）**：最贵也最稳的一条线。CN2 GIA 的 IP transit 价格能到 $120/Mbps，1Gbps 满带宽一个月理论账单能到 $10 万。容量有限，对 DDoS 不友好，但延迟和稳定性是最好的。
- **AS23764 CTGNet**：电信新加的选项，搬瓦工认为它实际表现和 CN2 GIA 基本等价。

搬瓦工在洛杉矶 USCA_9 机房把三网都接齐了：电信走 CN2 GIA（AS4809），移动走 CMIN2（AS58807），联通走 China Unicom Premium（AS10099）。这就是它主推的"三网 CN2 GIA"说法的来源——不是三条都叫 CN2 GIA，而是三网各自走 premium 级别的直连线路。

所以当你在选"美国 CN2 VPS"时，真正要问的是：**我买的是 CN2 GT 还是 CN2 GIA？三网都优化还是只优化电信？** 这比看 CPU 和内存重要得多。
